# stupid territorialism

You are a blue triangle on a street map. Plant flags at intersections, return to the first one and **enclose city blocks** to dominate them, while three bots (red, purple and orange) do the same, steal your territory and shoot at you.
The winner is whoever has the most territory after 4 minutes, or whoever reaches 50% of the map first.

<https://hernanisamuel.github.io/stupid-territorialism/> (computer or phone, no installation needed)

## How to run

You need [Node.js](https://nodejs.org) (tested with v22).

```bash
npm install
npm run dev        # opens at http://localhost:5173
```

| Command                | What it does                                                    |
| ---------------------- | --------------------------------------------------------------- |
| `npm run dev`          | Development server with automatic reload                        |
| `npm test`             | Runs the tests (Vitest, in Node, no browser)                    |
| `npm run sim`          | Bot tournament: thousands of matches without a screen, to measure changes to the bots |
| `npm run evolve`       | Automatic evolutionary search of a personality's parameters (~20 min) |
| `npm run typecheck`    | Only checks the types                                           |
| `npm run build`        | Production build in `dist/`                                     |
| `npm run build:single` | Generates **a single `.html`** file in `dist-single/`, to send to someone |

> **Don't open the root `index.html` with Live Server or by double-clicking.** It points to `src/main.ts`, and the browser
> does not run TypeScript: the page shows up without a map and with an empty scoreboard. Use `npm run dev`, or open the file
> generated by `npm run build:single` (`dist-single/index.html`), which works on any static server and even by double-clicking.

## Controls

| Key / mouse                      | Action                                                      |
| -------------------------------- | ----------------------------------------------------------- |
| `WASD` or arrow keys             | Walk along the streets (at intersections, turns onto the best-aligned street) |
| Right button                     | Plant a flag (while stopped at an intersection). 3+, then return to the 1st to close |
| Space or left button             | Shoot forward, along the street                             |
| `M`                              | Map overview                                                |
| Mouse wheel                      | Zoom                                                        |
| `R`                              | New match (new map)                                         |
| `N`                              | Toggle sound on/off                                         |

### On the phone (landscape)

Touch controls appear automatically on touch devices: a **joystick** that appears wherever you place your left thumb, and on the right the **shoot** (hold) and **plant flag** buttons. In the top corner there are small buttons for map,
sound, restart and fullscreen. With the device upright, the game pauses and asks you to rotate it. To test on a phone,
run `npm run dev -- --host` and open the network address Vite shows (computer and phone on the same Wi-Fi network), or use
Chrome's device mode (F12 → phone icon).

**Install it like an app** (optional). On Android with Chrome, open the game and use the menu (⋮) → *Install app* or
*Add to Home screen*: it opens fullscreen, in landscape, with its own icon. On iPhone with Safari, use *Share* →
*Add to Home Screen*. The installed app still needs an internet connection (there is no offline cache). Icons and settings
are in [`public/`](public/manifest.webmanifest).

Each bot plays differently: the **red** one hunts flags and the leader, the **purple** one is cautious and the **orange** one is greedy
(details in [`docs/BOTS.md`](docs/BOTS.md)). They dodge your shots and prefer to target whoever is winning.

Tips: touching an enemy flag **destroys the owner's entire chain**; walking on your own territory is 20% faster;
dying makes you lose the flags you haven't closed yet.

## Reproducible maps

Every map is born from a seed (shown in the browser console). Open `http://localhost:5173/?seed=123` to play the same
map again, with the same initial bot decisions.

## Publishing (GitHub Pages)

Every push to `main` runs [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml): it installs, runs the tests,
builds and publishes `dist/`. If a test fails, nothing is published.

One-time setup: **Settings → Pages → Build and deployment → Source: "GitHub Actions"**. The game is then served at
`https://<user>.github.io/<repository>/`, and `?seed=123` works there too, so you can share a map as a link.
Asset paths are relative (`base: './'` in `vite.config.ts`), so no repository name is hard-coded.

## Tuning the game

All parameters (speeds, number of bots, map size, match time, shooting mode...) are in
[`src/config.ts`](src/config.ts), each with a comment explaining what it does.
In development, `__game.CFG` in the console lets you change them live.

## Structure

```
src/
  main.ts        wires everything together and runs the main loop
  game.ts        creates matches and advances the simulation one frame
  config.ts      game parameters and teams
  types.ts       shared types
  core/          seeded random number generator
  map/           street graph, city blocks, procedural map
  entities/      agents, movement along streets, shots
  rules/         flags, loops, deaths, scoreboard, combat
  ai/            the bots: decisions, danger perception, planning, combat
  input/ render/ audio/ ui/    everything that touches the browser
tests/           automated tests
sim/             bot tournament (`npm run sim`) and evolutionary search (`npm run evolve`)
docs/            architecture and explanation of the bots
```

More details in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) and [`docs/BOTS.md`](docs/BOTS.md).

> The original single-HTML file remains at `stupid territorialism.html` for reference.
